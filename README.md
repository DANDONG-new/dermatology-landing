# 오브 피부과 랜딩페이지

`바로열기.cmd`를 더블클릭하거나 `index.html`을 브라우저로 열면 됩니다. 설치나 빌드가 필요하지 않습니다.

## 구성

- 프리미엄 브랜드 첫 화면과 AI 생성 인물 이미지
- 진료 철학, 피부 고민별 프로그램 필터와 상세 안내
- 공간 소개, 첫 방문 진료 과정, 자주 묻는 질문
- 예시 진료 시간과 상담 준비 창
- 모바일 메뉴와 하단 고정 상담 버튼
- 키보드 조작, 기본 입력 검증, 날짜별 상담 가능 시간

## 실제 병원에 적용할 때

현재는 **가상 브랜드의 디자인 시안**입니다. 외부에 배포하지 않았습니다.

1. `index.html`의 병원명, 진료 시간, 주소, 연락처, 의료기관 정보를 실제 정보로 바꿉니다.
2. `index.html`과 `app.js`의 프로그램 및 안내 문구를 실제 진료 내용에 맞게 검토합니다.
3. 실제 예약 접수를 위해 병원 예약 시스템 또는 서버를 연동하고 개인정보 안내를 준비합니다.
4. AI 이미지 대신 실제 공간 사진 등을 사용하려면 `assets/hero.webp`, `assets/space.webp`를 교체합니다.

상담 기능은 **내용 확인까지만 동작**합니다. 입력 정보는 서버로 전송하거나 저장소에 저장하지 않으며 상담 창을 닫으면 지워집니다. 진료 시간은 예시이고 공휴일은 달력에 반영하지 않습니다. 입력 시 실제 개인정보 대신 테스트용 정보를 사용하세요.

Google Fonts에서 웹폰트를 가져옵니다. 인터넷이 없으면 Windows의 바탕/맑은 고딕 등 대체 글꼴을 사용하며 이미지와 상호작용은 그대로 동작합니다. 외부 JavaScript 라이브러리는 없습니다.

## 주요 파일

| 파일 | 역할 |
| --- | --- |
| `index.html` | 문구와 페이지 구조 |
| `styles.css` | 색상, 서체, 반응형 레이아웃 |
| `app.js` | 프로그램 필터, 상담 체험, 모바일 메뉴 |
| `assets/` | 로고 아이콘과 로컬 WebP 이미지 |
| `DESIGN.md` | 디자인 기준과 이미지 생성 프롬프트 |
| `qa/verify.cjs` | 실제 Chrome/Edge 브라우저 검증 |
| `qa/results.json` | 최종 검증 결과 |
| `qa/desktop.png`, `qa/mobile.png` | 전체 페이지 화면 |

## 검증

현재 환경에서는 `node qa/verify.cjs`로 재검증할 수 있습니다. 설치된 Playwright 또는 Codex에 번들된 Playwright와 PC에 설치된 Chrome/Edge를 사용합니다. 이 테스트 도구는 사이트 실행에 필요하지 않습니다. 다른 PC에서는 Playwright가 제공되는 개발 환경에서 실행하세요.

검증 범위는 로컬 Chrome의 320~1920px 반응형 화면, 메뉴와 링크, 프로그램 필터 및 키보드 이동, 상세 안내, 상담 폼, 전화번호·날짜 검증, 예시 진료 시간, 입력값 삭제, 네트워크 미전송, 인터넷 차단 시 기본 동작입니다. 실제 휴대전화 기기나 운영 예약 시스템은 검증하지 않았습니다.

## GitHub Pages 배포

`.github/workflows/deploy-pages.yml`은 `main` 브랜치에 반영되면 정적 사이트를 GitHub Pages에 배포합니다. 저장소 설정의 **Settings → Pages → Build and deployment → Source**에서 **GitHub Actions**를 선택하세요. 배포 주소와 결과는 저장소의 **Actions** 탭에서 확인할 수 있습니다. 공개 사이트는 실제 병원 정보가 아닌 가상 브랜드 및 AI 콘셉트 이미지가 포함된 디자인 시안입니다.
